# **Список ассетов**

[[ГДД Мастер на день|Главный ГДД]]

## **Как делаем**

**Итог реализации.** В текущей версии игры все модели, текстуры и звуки созданы процедурно — кодом, без файлов моделей; Blender и сторонние библиотеки не понадобились. Таблицы ниже — исходный план производства, по которому сверялся объём работ.

| Способ | Что | Почему |
| :---- | :---- | :---- |
| **П** — процедурно в коде (Three.js) | мебель, коробки, техника простых форм, стены, полы, окна | единый стиль, нулевые лицензии, легко перекрашивать под локацию |
| **Б** — Blender, своя модель | сложные формы: кофемашина, VR-очки, машина для мячей, клиент | нужна выразительная форма, которую трудно собрать из примитивов |
| **CC0** — бесплатная библиотека моделей с лицензией CC0 (можно использовать без указания автора), с перекраской в палитру игры | мелкий декор: посуда, растения, книги | экономия времени; источники: Kenney, Quaternius, Poly Pizza (только CC0), ambientCG |
| **2D** — SVG/canvas | интерфейс, иконки, панели миниигр, тексты в сцене | чётко на любом экране, малый вес |

Правило: любой ассет из библиотеки перед добавлением переводится на общую текстуру-палитру и получает фаски/пропорции нашего стиля. Источник и лицензия каждого файла записываются в `CREDITS.md`.

Приоритет: **MVP** (минимальная играбельная версия) — нужно для полной игры с одной локацией; **Полная** — остальные локации; **Полировка** — если останется время.

## **1. Комнаты (10 заготовок)** Размер оболочки зависит от локации: общежитие 4,6 × 3,9 × 2,6 м, хрущёвка 5,2 × 4,3 × 2,5 м, новостройка 6,5 × 5 × 2,8 м, элитный ЖК 9,2 × 7 × 3,7 м, офис 10 × 7,6 × 3,2 м. Обе заготовки локации одинаковы по размеру и игровым точкам; меняются стены, пол, окно, свет и декор. Окно: маленькое (общежитие, хрущёвка), большое (новостройка), панорамное (элитный ЖК, офис).

| Локация | Заготовка | Неинтерактивный декор (6–10 шт.) | Способ | Приоритет |
| :---- | :---- | :---- | :---- | :---- |
| Общежитие | A: общая кухня | электроплитка, мойка, шкафчики, график дежурств, мусорное ведро, табуретки | П + CC0 | MVP |
| Общежитие | B: комната соседей | двухъярусная кровать, письменный стол, плакат, сушилка с бельём, тумбочка | П + CC0 | MVP |
| Хрущёвка | A: кухня-гостиная | ковёр на стене, сервант, газовая плита, кухонный уголок, люстра | П + CC0 | Полная |
| Хрущёвка | B: общая комната | диван-книжка, стенка, торшер, ковёр на полу, телевизор-тумба | П + CC0 | Полная |
| Новостройка | A: открытая кухня | кухонный остров, лампочка без плафона, стремянка, плёнка на мебели | П | Полная |
| Новостройка | B: рабочая зона | стол, офисное кресло, коробки, голые стены, рулон обоев | П | Полная |
| Элитный ЖК | A: гостиная | мраморный остров, панорамное окно, диван, дизайнерская полка | П + Б | Полная |
| Элитный ЖК | B: спортивная зона | тренажёр, стойка с ракетками, зеркало, полка кубков | П + Б | Полная |
| Офис | A: приёмная | стойка ресепшена, кулер, диван ожидания, логотип | П | Полная |
| Офис | B: открытый офис | столы с перегородками, мониторы, световые панели | П | Полная |

Окно: 5 видов за окном (2D-фон с параллаксом): двор общежития, двор хрущёвки, стройка, вечерний город, офисный центр. **2D**, Полная (общежитие — MVP).

## **2. Устройства (15)**

Каждое устройство: 3D-модель для комнаты (точка устройства) + 2D-панель «на верстаке» для миниигры.

| Локация | Устройства | 3D | 2D-панель | Приоритет |
| :---- | :---- | :---- | :---- | :---- |
| Общежитие | чайник, микроволновка, ноутбук | П | SVG | MVP |
| Хрущёвка | телевизор, стиральная машина, холодильник | П | SVG | Полная |
| Новостройка | умная колонка, посудомоечная машина, кондиционер | П | SVG | Полная |
| Элитный ЖК | VR-очки, кофемашина, машина для подачи мячей | Б | SVG | Полная |
| Офис | робот-пылесос, принтер, проектор | П | SVG | Полная |

Габарит каждой модели ≤ 1 × 1 × 0,6 м (ГДД). Все стоят на поверхностях 1,1 м.
