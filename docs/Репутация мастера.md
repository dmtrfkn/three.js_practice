# **Репутация мастера**

[Главный ГДД](https://docs.google.com/document/d/1HVynTNykcF7NOHy42FRExIpgXj8XORhC0k-wekOQvdc)

## **Смысл**

R — видимая игроку репутация мастера. В начале кампании она равна 0 и может принимать значения от −20 до \+20. Изменение записывается один раз при завершении заказа; итоговое значение ограничивается этим диапазоном и сохраняется.

## **Влияние**

Репутация влияет на вероятность инспектора при выборе следующего заказа. Для победы после прохождения всех локаций требуется R не ниже \+10. Она не меняет уже созданного клиента. Уровни бюджета и знания техники создаются для предложенных заказов отдельно от репутации.

## Расчёт по исходу заказа

## **Репутация рассчитывается один раз после конечного исхода заказа. Первое возражение клиента запоминается как признак недовольства; оно не изменяет R немедленно. Таблица задаёт итоговое изменение за заказ без нарушения. После успешного ремонта инспектора к этому результату добавляется штраф репутации за выявленное нарушение. Повторные попытки миниигры не дают новых начислений.**

## 

| Исход | Был отказ по цене | Попытка ремонта | Изменение R |
| :---- | :---- | :---- | :---- |
| Клиент оплатил, согласованная цена ≤ 0,90 × P \[новое\] | нет | успех с первой | \+3 |
| Клиент оплатил | нет | успех с первой | \+2 |
| Клиент оплатил | да, затем согласился | успех с первой | \+1 |
| Клиент оплатил | любое значение | успех со второй или позднее | 0 |
| Скандальный клиент ушёл с жалобой \[новое\] | заметил наценку от 1,30× | ремонта нет | −6 |
| Клиент ушёл после торга | два отказа | ремонта нет | −4 |
| Инспектор оформил нарушение | не применяется | после успешного ремонта | дополнительно −8 |

## Для завершённого заказа берётся ровно одна основная строка таблицы. При выявленном нарушении к ней прибавляется строка инспектора. Сумма применяется к текущей репутации и ограничивается диапазоном из раздела «Смысл». Уход клиента, оплата, штраф и итоговое изменение репутации помечаются в сохранении как обработанные события заказа. Повторная загрузка не повторяет их.
