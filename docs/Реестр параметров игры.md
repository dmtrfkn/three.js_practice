# **Реестр параметров игры**

[Главный ГДД](https://docs.google.com/document/d/1HVynTNykcF7NOHy42FRExIpgXj8XORhC0k-wekOQvdc)

## **Скрытость**

Игрок видит баланс M, репутацию R, число выявленных нарушений V, рыночную цену P, предложенную цену и оставшиеся вызовы. Бюджет, знание техники, срочность, настроение, предел согласия L, манера речи и роль клиента скрыты; настроение передаётся выражением лица и текстовой пометкой об интонации.

## **Параметры согласованных механик**

| Параметр | Значение / правило | Ед. | Игрок видит |
| :---- | :---- | :---- | :---- |
| R — стартовая репутация | 0; после заказа clamp(R+ΔR; −20; \+20); для победы R≥+10 | п. | да |
| V — старт нарушений | 0; второе выявленное нарушение завершает кампанию арестом | шт. | да |
| Заказов в локации | 3 выбранных заказа из 5 предложенных в каждой локации | шт. | да |
| Настроение N | при создании клиента: плохое 20 %, нейтральное 60 %, хорошее 20 %; после отказа понижается на одну ступень, нижняя граница — плохое | п. | косвенно |
| Осмотр | 4: 1 достоверный, 1 неоднозначный либо подозрительный, 2 нейтральных | шт. | объекты |
| Множитель цены m | ползунок 0,75×…2,00× с шагом 0,05×; предложенная цена \= round(P×m) до 1 ₽ | коэф. | да |
| Предел согласия L | L=P×(b+δн+δс); b=1,10/1,35/1,65 по бюджету; δн=−0,10/0/+0,10 по настроению; δс=+0,10 при высокой срочности, иначе 0 | ₽ | нет |
| Реакция обычного клиента | Pи≤P: согласие; выше P — однократная проверка обнаружения наценки; если не обнаружена, согласие при Pи≤L, иначе мягкое требование снизить | исход | реакция |
| Предел второго предложения C | C=min(L после ухудшения настроения; Pпред−0,05×P) после мягкого требования; после жёсткого C=0,95×P при среднем знании, 0,90×P при высоком | ₽ | нет |
| Второе предложение | второе предложение строго ниже первого; при цене≤C согласие, иначе клиент уходит | исход | реакция |
| Вероятность проверки Q | первый вызов: 0 %; далее Q=min(40; max(5; 20−R)) %, роль выбирается один раз после выбора заявки | % | нет |
| Безопасная цена проверяющему | согласованная цена ≤1,20×P; инспектор принимает любую цену и не торгуется | коэф. | исход |
| Штрафы | каждое нарушение: штраф 2×(согласованная цена−P) и дополнительно −8 R; при втором — арест после протокола | ₽ | да |
| Признаки инспектора | нет в первом вызове; подозрительный предмет: у инспектора 85 %, у обычного клиента 20 %; формальная речь: у инспектора 80 %, у обычного 20 %; ответ о подозрительном предмете выбирается из общего набора по манере речи и роль не выдаёт | правило | нет |
| Обнаружение наценки | при m≤1,20: 0 %; при m\>1,20: min(95; k+50×(m−1,20)) %, где k=10/35/60 по знанию техники | % | нет |
| Согласие после обнаружения | при хорошем настроении и цене≤L: 30 %; иначе 0 % | % | реакция |
| Требование скидки | если наценка обнаружена и согласия нет: 0/40/65 % при низком/среднем/высоком знании | % | реплика |
| Манера речи | инспектор: формальная с шансом 80 %; обычный клиент: формальная с шансом 20 %; иначе разговорная | % | по репликам |
| Вопросы в диалоге | 2 выбранных вопроса; всегда есть 2 базовых, каждый осмотренный предмет добавляет 1 | шт. | список |
| Стартовый баланс | 0 | ₽ | да |
| Предложения в локации | 5: два дешёвых устройства, два средних, одно дорогое; можно выбрать до 3 | шт. | да |
| Общежитие | цены 1 500/2 500/3 500; квота 8 000; переезд 1 000 | ₽ | да |
| Хрущёвка | цены 4 000/5 000/6 000; квота 24 000; переезд 3 000 | ₽ | да |
| Новостройка | цены 5 000/8 000/9 000; квота 48 000; переезд 5 000 | ₽ | да |
| Элитный ЖК | цены 12 000/14 000/18 000; квота 94 000; переезд 8 000 | ₽ | да |
| Офис | цены 15 000/18 000/22 000; мастерская 150 000 и R≥+10 | ₽, п. | да |
| Предел честного заработка | за 3 лучших заказа в каждой локации: 153 500 до переездов; после переездов 136 500 (меньше 150 000 — без наценки победа невозможна) | ₽ | нет |
| Неисправности на устройство | 2 варианта, равновероятно при создании предложения | шт. | после диагностики |
| Шанс варианта неисправности | 50 % для A и 50 % для B | % | нет |
| Время миниигры | 20 на каждую попытку | с | да |
| Оплата после проигрыша | 80 % согласованной цены после первого проигрыша; дальше не уменьшается | % | после оплаты |
| R: ремонт с первой попытки | без возражения по цене: \+2 | п. | после заказа |
| R: ремонт после торга | было возражение; ремонт с первой попытки: \+1 | п. | после заказа |
| R: повтор ремонта | успех со второй или позднее попытки: 0, независимо от торга | п. | после заказа |
| R: скидка [новое] | согласованная цена ≤0,90×P, ремонт с первой попытки, без отказа: \+3 вместо \+2 | п. | после заказа |
| R: уход клиента | второй отказ по цене: −4 | п. | после заказа |
| Намёк на срочность в предложении | появляется с шансом 50 % независимо от уровня срочности; при появлении текст правдивый | % | строка или её отсутствие |
| Время осмотра | 30 | с | да |
| Камера: углы и обзор | старт 0°/0°; по горизонтали −65°…+65°; по вертикали −25°…+25°; вертикальный угол обзора 60° | градусы | поворот камеры |
| Комната: размеры и точки [новое] | по локациям: общежитие 4,6×3,9×2,6; хрущёвка 5,2×4,3×2,5; новостройка 6,5×5×2,8; элитный ЖК 9,2×7×3,7; офис 10×7,6×3,2 м; камера (0;1,6;0,4) везде; точки клиента, устройства и A–D — таблица «Геометрия сцены» в документе генерации | м | комнату |
| Внешность клиента [новое] | по имени и номеру заказа: рост 1,66–1,88 м, телосложение, возраст, причёска, борода/усы, очки; одежда и аксессуары по локации (худи → кардиган → рубашка → водолазка/пиджак → рубашка с галстуком и бейджем) | правило | да |
| Поверхности и модели | каждая из 4 точек: поверхность 1,1×1,1 м на высоте 1,1 м; модель не более 1×1 м по основанию и 0,6 м по высоте | м | предметы |
| Имена клиентов | 15 имён из фиксированного списка в документе генерации; равновероятно без повторов среди 5 предложений локации | шт. | имя |
| Общая громкость | 0…100 %; шаг 10 %; начальное значение 100 % | % | настройку |
| Чувствительность камеры | 0,5×…2,0×; шаг 0,1×; начальное значение 1,0× | коэф. | настройку |
| Бюджет по локациям | низкий/средний/высокий: общежитие 60/35/5 %; хрущёвка 50/40/10 %; новостройка 30/50/20 %; элитный ЖК 10/35/55 %; офис 10/40/50 % | % | нет |
| Знание техники по цене | низкое/среднее/высокое: дешёвый заказ 60/30/10 %; средний 30/50/20 %; дорогой 10/40/50 %; группа заказа = ценовая группа устройства (2 дешёвых, 2 средних, 1 дорогое) | % | нет |
| Срочность клиента | низкая/средняя/высокая: 30/40/30 % для любого предложения | % | косвенно |
| Вид подозрительного предмета | диктофон/телефон/папка: общежитие 60/30/10 %; хрущёвка 50/35/15 %; новостройка 35/40/25 %; элитный ЖК 20/40/40 %; офис 10/30/60 % | % | предмет |
| Тип достоверного признака | бюджет/знание техники/срочность: по 1/3 для каждой категории | доля | предмет |
| Примета клиента [новое] | на карточке предложения с шансом 50 %; тип бюджет/знание техники по 50 %; текст правдивый | % | строка или её отсутствие |
| Типы миниигр [новое] | замена детали, прозвонка цепи, калибровка, разборка и чистка; тип задан неисправностью | шт. | да |
| Ошибки в миниигре [новое] | замена: провал на 2-й ошибке; прозвонка, калибровка, разборка: на 3-й ошибке | шт. | да |
| Целевой успех миниигры с первой попытки [новое] | 85–90 % для среднего игрока; проверяется плейтестом | % | нет |
| Выход из игры во время попытки ремонта [новое] | попытка засчитывается проваленной | правило | да |
| Скандальный клиент [новое] | общежитие/хрущёвка 5 %; новостройка 10 %; элитный ЖК/офис 15 %; у инспектора нет | % | нет |
| Жалоба скандального [новое] | наценка замечена и m≥1,30: уход без торга, −6 R, \+10 п.п. к шансу инспектора на следующий вызов | правило | реакция |
| Примета скандального [новое] | «Всё проверю, знаю свои права» с шансом 70 %; у обычных не бывает | % | строка |
| Заготовки комнат | 2 в каждой из 5 локаций; каждая содержит 2 закреплённых нейтральных предмета и 4 универсальные точки A–D | шт. | комнату |
