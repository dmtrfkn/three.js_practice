# Мастер на день — MVP

Браузерная 3D-игра о выездном мастере: осмотр квартиры, разговор с клиентом, назначение цены и риск проверки.
ГДД — в `../docs`, арт-дирекшн — `../docs/19_art_direction.md`, техплан — `../docs/21_tech_plan.md`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # тесты правил ГДД + симуляция баланса на ядре
npm run build      # сборка в dist/ (статические файлы для itch.io)
```

Готовый архив для itch.io (HTML5, «This file will be played in the browser»): `release/master-na-den-web.zip`.

## Что есть в MVP

- Вся кампания: 5 локаций × 3 вызова, квоты, переезды, победа (мастерская), поражения (деньги, репутация, арест).
- 10 процедурных комнат разного размера (общежитие 4,6 × 3,9 × 2,6 м … офис 10 × 7,6 × 3,2 м), у каждой локации свой свет, материалы и декор.
- 15 устройств, 37 предметов осмотра, клиенты с разной внешностью (телосложение, возраст, причёска, борода, очки, одежда по социальному слою) и тремя выражениями лица.
- Осмотр с таймером 30 с, контур при наведении, карточки-листки; разговор (2 вопроса), автоматическая диагностика, цена на «рулетке», торг, скандальный клиент, инспектор и протокол.
- 4 миниигры ремонта: замена детали, прозвонка цепи, калибровка, разборка и чистка.
- Сохранение после каждого действия (localStorage): загрузка не меняет исходы и не дублирует деньги.
- Процедурный звук (Web Audio), настройки громкости и чувствительности камеры, управление с клавиатуры (Tab/Enter/Esc/стрелки/пробел).
- Адаптив под телефоны: тач-управление камерой и предметами, панели-шторки в портрете и боковые панели в ландшафте, вертикальная раскладка миниигр, подсказки «тап/пальцем» вместо «мышь/Esc», облегчённый рендер на сенсорных устройствах. Проверка: `node tests/e2e/mobile.mjs <url> <папка>` (iPhone, портрет и ландшафт).

## Структура

```
src/core/       чистая логика ГДД (без DOM): params.ts — все числа реестра, campaign.ts — жизненный цикл
src/scene/      Three.js: kit (инструменты моделирования), props (предметы и устройства), decor (комнаты), client, RoomScene
src/minigames/  четыре миниигры на Canvas 2D
src/ui/         Vue 3: экраны и компоненты в стиле «бумаги мастера»
src/audio/      процедурные звуки
tests/core      Vitest: формулы реестра и жизненный цикл заказа
tests/sim       симуляция 3000 кампаний на реальном ядре
tests/e2e       Playwright: сквозные сценарии со скриншотами (нужен запущенный dev-сервер)
```

`scene-test.html?loc=0..4&preset=0|1` — стенд для просмотра комнат без прохождения.
В консоли браузера доступен `window.__game` (состояние и действия) — для автотестов и отладки.
